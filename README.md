# ÉLVARÉ — Luxury Perfume E-Commerce Website

A modern, responsive luxury perfume e-commerce concept built with React and Vite. ÉLVARÉ combines an elegant dark aesthetic with a premium shopping experience, featuring a curated fragrance collection and interactive shopping functionality.

## ✨ Features

- **Luxury Dark UI:** Minimal, elegant, and modern visual design.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Product Collection:** Explore six signature fragrances.
- **Product Details:** Individual pages for each perfume.
- **Shopping Cart:** Add and manage selected products.
- **Wishlist:** Save favorite fragrances.
- **Search & Filtering:** Browse and filter the fragrance collection.
- **LocalStorage:** Cart and wishlist data persist in the browser.
- **Multi-Page Navigation:** Smooth navigation across the website.
- **Demo Checkout:** Interactive checkout experience for demonstration purposes.

## 🚀 Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/AlinaZahraHub/elvare-luxury-perfume-store.git
```

**2. Open the project folder**

```bash
cd elvare-luxury-perfume-store
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Create a production build**

```bash
npm run build
```

## 📌 Project Notes

- ÉLVARÉ is a self-initiated portfolio concept project for a fictional luxury perfume brand.
- This project is developed for demonstration and portfolio purposes.
- Cart and wishlist functionality use browser LocalStorage.
- Checkout is a demonstration only; no real payments or orders are processed.
- The contact form is a UI demonstration and does not send emails.
- No backend, authentication system, or payment gateway is integrated.
